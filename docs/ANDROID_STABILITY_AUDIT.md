# Android stability audit

Base revision `bc0acc8`. The working branch is `android-stability`. Android-only CI is the delivery target. Desktop and iOS source remain available for compatibility and future maintenance. Existing chats, workspaces, MCP settings, schedules, and tool preferences use their original storage keys.

## Defects and evidence

| Severity | Subsystem and entry point | Evidence and reproduction | Change and verification |
| --- | --- | --- | --- |
| Critical | Startup and Hive, `main.dart`, `HiveService.init` | Hold Hive initialization for more than ten seconds. The old timeout returned a fresh Hive service with uninitialized box fields. Bad Hive checksums can also complete an internal Hive opening future with an otherwise unobserved error. | Startup renders loading and retry states and constructs consumers after storage opens. Hive corruption detection preserves the unreadable file. Widget test delays startup, injects failure, and retries. Hive test corrupts a real file, verifies it is unchanged, restores healthy bytes, and reopens it. |
| High | Chat and inference lifecycle, `ChatController.openChat`, `InferenceService.stopGeneration` and `resetConversation` | Switch chats during attachment import or a delayed reset, then send immediately. Previously the next request could start before asynchronous native stop and reset finished. A delayed old submission could compete with the new turn. | Queue cancellation and context transitions, invalidate the outgoing generation, and check the submitted session before consuming results. Tests cover delayed reset and switching during import. |
| High | LiteRT bridge, `FlutterLitertLmPlugin` and `MethodChannelFlutterLitertLm.sendMessageStream` | Static evidence. Dart previously requested generation before subscribing. An older coroutine also wrote through the global mutable event sink, so a subsequent listener could receive the previous flow's output or end signal. | Install the listener before launching generation. Each coroutine owns its sink and cancellation job. The Dart channel test passes. Isolated Kotlin API compilation passed with the dependency metadata check bypassed. Native device and full Gradle verification remain pending. |
| High | Cluster worker startup, `ClusterService.startWorker` and `_watchWorker` | Inject a native worker start exception. The old error path retained the worker-request flag, leaving the logical role selected. Status polling could also overlap and race a role change. | Serialize role and port changes, fence stale polls, poll startup with a deadline, and report the error while the role is Off. Channel test covers failure, retry and a concurrent stop request. |
| High | Cluster recovery, `ClusterService._startWatchdog`, `relocateWorkers` | Static evidence. Probe futures overlapped. A successful address relocation was removed from the unreachable list, so the watchdog could skip a reload even with an active native RPC endpoint at the old address. A probe could finish after another model began loading. | Check the actual active endpoint set and recheck model revision and busy state before watchdog reload. Native RPC recovery still needs physical-device verification. |
| High | Chat tools, `AgentService.wantsTools`, `_toolsFor` and `runToolLoop` | Static evidence. Keyword-gated tool availability varies with wording and language. A repeated search can evade argument-based detection through minor changes. The legacy loop can return explanatory text in place of a tool result. | Ordinary text and voice Chat use the structured adapter and a per-turn allowlist. Tests cover an unexecuted action claim, malformed arguments, actual tool-result attachments, tool deadlines, and repeated results under different queries. Legacy explicit media shortcuts remain for compatibility. |
| High | Search, `WebSearchService._provider` | Inject HTTP 429, HTTP 503, a timeout, a transport error, malformed feed XML and a non-HTML response. Previously these could all become an empty list. | Typed provider results distinguish failures from valid empty responses. The model can refine a query. Sources and full bounded results are kept with the assistant message separately from model context. HTTP mocks and a Chat Controller research test cover the new path. |
| Medium | Settings, `HiveService.getSetting`, startup device defaults | A stored value with a legacy type could throw at startup. Older profiles lacking the device-default marker could have existing inference settings overwritten. | Wrong-type values fall back for typed callers without deletion. First-run inference defaults fill missing values before SettingsController is registered. |
| Medium | Benchmark, `InferenceService.generate`, `runBenchmark`, model comparison | Static evidence. The old measure counted Dart callbacks as tokens and included teardown in the denominator. LiteRT can batch several chunks into one callback. | Use a monotonic clock and measure first output and the interval between observed chunks before UI batching. Report chunk rate, measured load time, and the runtime's backend label. UI can cancel a benchmark. Native tokenizer throughput and app memory remain unmeasured. |

## Chat behavior and constraints

- The model can choose web search, calculator, bounded exact integer arithmetic, context reading, Pollinations, TTS, and installed voice discovery. Voice calls expose research, calculation and selected context. Existing explicit online-image/edit and narration workflows are retained. Standalone Agent navigation, scheduled agent startup, MCP connection startup and MCP controls are disabled.
- The default is five executions per turn. Chat Tools & Permissions allows one through ten. The turn has a three-minute deadline, one malformed-response repair, duplicate-query checks and result-based progress checks. Failed and cancelled work is recorded as such. Search sources are provider excerpts and retain provenance. The adapter relies on the model to classify factual intent and report uncertainty. Citation IDs are checked for existence. Claim-level entailment and honest free-form wording remain model-dependent.
- Native function calling remains unverified. The local GGUF API supplies templated text. The LiteRT Dart plugin advertises tool fields, but the Android wrapper reads `toolsList` without applying it to `ConversationConfig`. The app uses a JSON adapter for local and cloud. Native function execution needs a verified compatible model, Android tool registration and end-to-end result handling.
- Chat never executes arbitrary Python. The bounded calculator and exact decimal integer aggregation have no file, process or network operations. This supports numeric computation and simple list aggregation. Python programs, general structured-data transformations and imports are outside this milestone. The manual Alpine terminal remains a separate user-operated feature.
- Images use the existing workspace attachment renderer with viewing and saving. TTS validates installed model and speaker choices and saves a WAV attachment with playback available from the file sheet. A synchronous native TTS chunk can continue until it returns after cancellation. Structured audio saves use unique filenames. Native voice selection, playback and attachment recovery require Android checks. Live anonymous Pollinations Sana returned a valid 256 × 256 JPEG and the modern image catalog returned HTTP 200. Keyed generation and editing were not exercised against the live service.

## Open findings

- **High, unverified on device.** A worker that disconnects after visible output may leave an incomplete response. Automatic generation recovery is allowed only before first output. Reproduce with documented native layer placement and terminate the worker mid-decode. Verify the outcome and next-turn recovery.
- **Medium, static evidence.** `ChatController._submitMessage` replaces an edited message and deletes later messages through separate Hive operations. An interrupted write can leave part of the old conversation. Reproduce by stopping the Android process during editing or injecting a failure in one disk operation. A resumable persistence change still needs design and regression coverage.
- **Medium, static evidence.** `DownloadQueue._pump` persists the active item, then clears it once its polling window ends. Native download continuation and queue recovery after the six-hour polling deadline need a fault-injection test with an active Android download.
- **Medium, unverified on device.** `FlutterLitertLmPlugin.handleCountTokens` returns a placeholder. Actual token throughput and process PSS require native measurement on each model and backend. Current displays use output-chunk units.
